# Chinese Auction System

## English

### Technologies Used
- **Frontend**: Built with Angular and PrimeNG  
- **Backend**: Built with .NET Core API  
- **Database**: SQL Server

### Local Installation Instructions
To run the project locally, follow these steps:

1. Clone the repository:  
   `git clone https://github.com/Avigail3648/Chinese-Auction-System.git`

2. Navigate to the project directory:  
   `cd Chinese-Auction-System`

3. Install the dependencies for the Backend:  
   `dotnet restore`

4. Run the API server:  
   `dotnet run`

5. Install the dependencies for the Frontend:  
   `npm install`

6. Start the development server:  
   `ng serve`

7. Open your browser and go to `http://localhost:4200` to view the project.
